# Decisões arquiteturais

Este diretório contém registros de decisões arquiteturais (ADRs) do Switch Auto.

Cada decisão possui um estado:

- `Proposta`: ainda pode mudar sem processo formal;
- `Aceita`: orienta a implementação;
- `Substituída`: foi trocada por uma decisão posterior;
- `Rejeitada`: considerada, mas não adotada.
